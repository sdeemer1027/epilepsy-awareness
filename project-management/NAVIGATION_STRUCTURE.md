# Purpose

This document defines the navigation structure of the Epilepsy Support Platform (ESP).

Navigation should be simple, predictable, accessible, and consistent across all devices.

---

# Navigation Principles

The platform follows these principles:

- Keep important actions within two clicks.
- Never overwhelm new users.
- Use progressive disclosure for advanced features.
- Maintain consistent menus across desktop and mobile.
- Prioritize accessibility (WCAG 2.2 AA target).
- Display only features the current user is authorized to access.
