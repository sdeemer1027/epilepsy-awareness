# Purpose

This document describes the expected journeys users will take through the Epilepsy Support Platform (ESP).

The objective is to ensure that every feature supports a real user need and that users can accomplish their goals with minimal effort.

---

# Journey 1 – Public Visitor

## Goal

Learn about epilepsy and discover the resources offered by ESP.

### Typical Journey

```
Home
    ↓
Learn About Epilepsy
    ↓
Browse Articles
    ↓
Download Resources
    ↓
View Upcoming Events
    ↓
Register for an Account
```

### Success Criteria

- Finds reliable information quickly.
- Understands what ESP offers.
- Creates an account if additional features are desired.

---

# Journey 2 – New Member

## Goal

Create an account and begin managing epilepsy-related information.

### Typical Journey

```
Register
    ↓
Verify Email
    ↓
Accept Privacy Policy
    ↓
Complete Profile
    ↓
Add Emergency Contact
    ↓
Add Caregiver (Optional)
    ↓
Add Physician (Optional)
    ↓
Record First Seizure
    ↓
Add Current Medications
    ↓
Receive Welcome Resources
    ↓
Join Community
```

### Success Criteria

- Profile is complete.
- Emergency information is available.
- First medical records are entered.
- User understands the dashboard.

---

# Journey 3 – Returning Member

## Goal

Manage daily health information.

### Typical Journey

```
Login
    ↓
Dashboard
    ↓
Today's Medication
    ↓
Record Seizure (if needed)
    ↓
Review Appointments
    ↓
Read Notifications
    ↓
Visit Community
```

### Success Criteria

- Daily tasks completed quickly.
- Dashboard highlights important actions.
- User feels supported rather than overwhelmed.

---

# Shared Design Principles

Every journey should:

- Require the fewest practical steps.
- Be accessible on desktop, tablet, and mobile.
- Respect user privacy.
- Provide contextual help.
- Clearly indicate progress.
- Allow users to resume interrupted tasks.
