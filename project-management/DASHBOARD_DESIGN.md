# Purpose

This document defines the dashboard layouts for each user role within the Epilepsy Support Platform (ESP).

Dashboards should present the most important information first, minimize unnecessary navigation, and guide users toward their next action.

---

# Global Dashboard Standards

Every dashboard should include:

- Page title
- Breadcrumb navigation
- Notification center
- Quick action buttons
- Responsive layout
- Accessibility support (WCAG 2.2 AA)
- Role-based content
- Recent activity summary

---

# Dashboard Notification Levels

Notifications should be grouped by priority.

## Critical

Immediate action required.

Examples:

- System outage
- Emergency alert
- Failed backup

---

## High

Should be addressed today.

Examples:

- Moderation reports
- Missed medication reminder
- Upcoming appointment

---

## Normal

General information.

Examples:

- Community replies
- New articles
- Event reminders
