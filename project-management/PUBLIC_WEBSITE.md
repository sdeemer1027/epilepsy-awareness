# Purpose

This document defines the public-facing structure of the Epilepsy Support Platform (ESP).

The public website should educate, support, and encourage visitors while providing clear paths to registration, community engagement, and available resources.

The website must remain accessible, trustworthy, and easy to navigate.

---

# Primary Goals

The public website exists to:

- Educate visitors about epilepsy.
- Promote epilepsy awareness.
- Provide trusted resources.
- Encourage community participation.
- Support caregivers and families.
- Promote upcoming events.
- Encourage donations and partnerships.
- Provide access to the member portal.

# Accessibility Goals

The public website should:

- Meet WCAG 2.2 AA guidelines.
- Support keyboard navigation.
- Support screen readers.
- Use sufficient color contrast.
- Avoid flashing content.
- Provide descriptive link text.
